# Telehealth Web App

This directory contains a minimal Node.js web application that serves a static telehealth website.

## Usage

Run the server locally:

```bash
npm start
```

The site will be available at `http://localhost:3000`.

### Running tests

```bash
npm test
```

## Deployment

Deploy `server.js` and the `public` folder to any Node.js capable host. The app has no external dependencies.
