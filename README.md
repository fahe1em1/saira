# Bid Writing Website

This repository contains a simple Flask application that allows users to submit and view bid proposals. Bids are stored in memory and displayed on the main page.

## Requirements

- Python 3.11+
- Flask 2+

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Running the Application

Start the server by running:

```bash
python app.py
```

Then open `http://localhost:5000` in your browser.
